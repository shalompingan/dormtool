# 🛠 DormTool

Free interactive tools for college students. From move-in to move-out, from laundry to lease signing — everything you need in one place.

[Live Demo → https://dormtool.com/](https://dormtool.com/)

## Tools

- Dorm Essentials Checklist
- Dorm Roommate Agreement Generator
- Dorm Laundry Hub
- Dorm Move-Out Checklist
- Moving Cost Calculator
- First Apartment Checklist
- Rent Affordability Calculator
- Roommate Bill Splitter
- Student Loan Calculator
- GPA Calculator
- Dorm Budget Calculator

## Tech

Single-file HTML — no frameworks, no databases, no signups.
